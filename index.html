BraceScripts Assistant demo build

The same chatbot, three businesses.

Switch persona below. The code does not change — only the facts file and the config in business/. That is the whole pitch: installing it for a new client is content work, not code work.

Every persona on this page is a demonstration. Prices, hours and order records are sample data, not a live business — except where a real business is named, and then only the facts they supplied.

What it does

  • Answers only from a facts file the owner writes. If the answer is not there, it says so.
  • Checks an order, booking or transaction by reference and phone. Both must match.
  • Hands over to WhatsApp with the context pre-filled when it cannot help.

What it never does

  • It does not invent prices, times or policies. A missing fact is a refusal, not a guess.
  • It cannot take payments, change records or grant access. It has no such ability.
  • It never asks for card numbers, OTPs, PINs, passwords or seed phrases.

Install on any site

One script tag. Same-origin or cross-origin.

<script src="/widget/chat-widget.js"
  data-endpoint="/api"
  data-persona="food"
  data-accent="#62110c"
  defer></script>

The full procedure, including the two Netlify environment variables a client site needs, is in docs/INSTALL.md. It is not published on this page by design — this page is the demo, not the documentation.
